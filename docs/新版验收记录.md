验收日期：2026-10-06。材料均为中性虚构样例，没有调用付费模型接口。

- 49项离线自动化测试通过，包含原有27项回归。
- 新版接口完成后台分析、真实阶段回调、结构化结果、报告与DOCX下载。

## 复验方式

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

浏览器复验先启动临时服务，它会准备虚构DOCX和空历史目录：

```powershell
.\.venv\Scripts\python.exe tests\browser_preview.py
```

有Playwright CLI及Edge的环境可在项目根目录运行：

```powershell
npx --yes --package @playwright/cli playwright-cli -s=jobcopilot-check open http://localhost:8503/#/new --browser msedge
npx --yes --package @playwright/cli playwright-cli -s=jobcopilot-check run-code --filename tests/check_browser.js
npx --yes --package @playwright/cli playwright-cli -s=jobcopilot-check close
```

复验脚本会删除它在临时服务中创建的记录，不能将其指向正式服务。
重复运行前，应重启临时服务以获得空历史目录。
