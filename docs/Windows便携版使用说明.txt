JobCopilot Windows便携版

目标平台：Windows 10/11，64位（x64）。
目前在Windows 11 x64完成验证，Windows 10及其他电脑仍需试用确认。
不需要安装Python、pip或运行命令。

使用方法
1. 下载JobCopilot-Windows-x64.zip，右键选择“全部解压缩”。
2. 打开解压后的JobCopilot文件夹，双击JobCopilot.exe。
3. 浏览器会自动打开；请保留同时出现的运行窗口。
4. 在网页填写你自己的DeepSeek API Key，上传简历或粘贴文字，再填写岗位描述。
5. 点击“开始分析”。上传DOCX并成功生成后，可下载保留原模板的定制简历。

退出方法
请等待当前分析完成，再关闭JobCopilot运行窗口。
仅关闭浏览器标签页不会停止本机服务。

注意事项
- 必须先解压，不能直接在ZIP压缩包里运行。
- 不要删除、移动或单独复制JobCopilot.exe旁边的_internal文件夹。
- 重复双击会打开已经运行的便携版，不会再启动一份。
- 如果默认端口被其他服务使用，程序会自动尝试附近空闲端口，不会关闭其他程序。
- 浏览器未自动打开时，把运行窗口显示的网址复制到浏览器。
- 历史保存在本机 %LOCALAPPDATA%\JobCopilot\history，不在程序文件夹里。
- 更新时先关闭旧程序，再解压新版到新的文件夹；不要删除用户数据目录。
- 源码版原有历史不会自动迁移到便携版，源码版数据仍留在原项目的output/history中。
- 本包不包含任何人的Key、简历或历史报告。
- 真实分析会发送材料到DeepSeek API并产生费用，一轮分析有多个请求，失败可能自动重试。
- 建议先脱敏。AI建议、简历事实和Word分页都需要人工检查。

下载与安全
请只从 https://github.com/BSD-001/JobCopilot 的Releases下载便携ZIP。
本版没有做付费代码签名，Windows可能提示来源不明。
不要关闭安全软件来运行；请先核对下载来源和随包公布的SHA256，不确定时停止运行。
GitHub的Code / Download ZIP下载的是源码，不是Windows便携版。
